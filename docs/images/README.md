# Repository artwork

- `identity-studio-banner.png`: the full-resolution README cover.
- `identity-studio-social.jpg`: an optimized JPEG of the same cover for GitHub's social preview.
- `identity-studio-preview.jpg`: an actual screenshot of the local studio, with a fresh sample draft.

The cover follows the [AI Employee Lab design direction](../DESIGN.md): white, near-black, pink-red, condensed headlines, and geometric avatar illustrations. It is promotional artwork; the screenshot shows the actual product.

The banner was created with the built-in imagegen tool on September 16, 2026. The social image is a JPEG export of that artwork.
